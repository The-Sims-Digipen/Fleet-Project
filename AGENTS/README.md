# Agent context

These files contain maintainer/LLM context that is useful when changing the project but is not required reading for team members implementing assigned work.

- `planning-guidance.md` - rules for keeping implementation features appropriately scoped and team-facing documentation concise.
- `source-requirements.md` - requirements cross-check against the supplied PDF and DOCX briefs.
- `verification.md` - detailed technical acceptance and feature/test traceability.
- `typed-objects-plan.md` - implementation planning context for the typed 3D object/model architecture.
