# F08 — Power and Feasibility Panel

## Goal

Create the frontend UI that summarizes whether the selected plan fits within the site's available electrical capacity.

## What this feature should accomplish

Display:

- Site connection limit.
- Estimated peak demand.
- Available capacity.
- A clear status or warning state.

## Required stub states

- `Within Capacity`
- `Power Limit Exceeded`

The warning state should be visually obvious and should not rely on color alone.

## Stub behavior

- Use mock values.
- No charging, demand, or feasibility calculations are required this week.

## Done when

The panel clearly communicates the three required power values and how a feasible versus overloaded plan will be presented.
