# F02 — Fleet Management Panel

**Owner:** Jarrel Tay Wee Han

## Goal

Create the frontend UI for viewing and managing all vehicles in the fleet. This week is UI-only and should use mock vehicle data.

## What this feature should accomplish

- Show all vehicles in a table or list.
- Provide Add, Edit, and Delete vehicle controls.
- Allow a vehicle to be assigned a vehicle preset through a dropdown.

## Required vehicle information

Each vehicle row should show:

- Vehicle name or ID.
- Current vehicle preset.
- Annual distance, mileage, or utilisation.
- Planned transition year.

## Stub behavior

- Use mock vehicle data only.
- Controls do not need to modify real application state yet.
- The layout should be suitable for larger fleets and should not assume exactly 100 vehicles.

## Done when

The fleet can be visually inspected and the intended add/edit/delete/preset-assignment workflow is clear from the UI.
