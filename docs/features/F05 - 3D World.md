# F05 — 3D World

**Owner:** Chew Shee Yang

## Goal

Create a code-driven stub 3D depot world. Do not rely on Blender-authored depot geometry for this initial implementation.

## What this feature should accomplish

- Create the 3D viewport area.
- Render an empty or simple stub depot scene.
- Render placeholder vehicles.
- Render placeholder parking bays.
- Establish the basic look and spatial direction of the future depot digital twin.

## Stub behavior

- Geometry may be simple primitives created in code.
- Real project/fleet data is not required yet.
- Detailed depot authoring, production vehicle assets, charger placement, and simulation-driven state are outside this week's scope.

## Done when

The application has a visible 3D depot area containing simple parking and vehicle placeholders that can later be driven by real project data.
