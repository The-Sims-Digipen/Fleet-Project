# F04 — Simulation Settings

**Owner:** Elijah Chua Jye Kang

## Goal

Create a frontend panel for the assumptions required by the simulation.

## Required settings for the stub

- Fuel price.
- Electricity price.
- Site connection / power limit.

## Stub behavior

- Values may be placeholders or mock values.
- Inputs do not need to affect calculations yet.
- Organize the panel so more simulation assumptions can be added later without redesigning it.

## Done when

The user can clearly see where simulation assumptions will be viewed and edited.
