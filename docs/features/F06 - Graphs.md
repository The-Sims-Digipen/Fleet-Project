# F06 — Graphs

## Goal

Create the frontend financial graph UI that communicates when a transition plan becomes more profitable than keeping the current fleet.

## What this feature should accomplish

- Show a cost-over-time graph.
- Show a baseline curve representing no transition to EV.
- Show a transition-plan curve representing an EV transition scenario.
- Clearly indicate the break-even / payback year where the transition plan becomes cheaper or more profitable than the baseline.

## Stub behavior

- Use mock data only.
- No real simulation or financial calculations are required yet.
- The legend, axis labels, units, and break-even marker should make the intended meaning obvious.

## Done when

A user can understand the intended baseline-vs-transition comparison and identify the mocked break-even point from the graph.
