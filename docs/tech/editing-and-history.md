# Editing and history

The saved baseline is the complete version 1 Project document from the last successful save; dirty state compares the current document with that baseline. It is distinct from Undo history and from an active edit.

`beginEdit`, `commitEdit`, and `cancelEdit` define an active edit: continuous previews either become one undo step or are discarded back to the active edit's starting document. Number fields preview valid values while typing, commit on blur or Enter, and cancel on Escape. Sliders group pointer drags and held arrow keys; pointer cancellation restores the starting value. Color edits group until the picker loses focus. Presets and checkboxes are discrete edits. Blank or invalid numeric drafts stay local to their control.

Selection, panel collapse, history navigation, and interaction/transform-tool setting changes finish pending edits. One Project history covers scenarios, vehicles, presets, analysis settings, depot transforms, and vehicle transforms. Selection, interaction mode, selected year, lighting, and camera movement are Project-runtime-only and excluded from undo. Workspace mode and panel expansion are application UI state in `appStore`, are also excluded from undo, and remain stable when the open Project changes. Runtime-only continuous controls use their own edit snapshot so cancellation restores the starting runtime value without creating Project history. Viewport gizmo drags use the Project-document lifecycle: pointer down begins an edit, live transforms update the Project document, pointer up commits one undo step, and Escape cancels back to the drag baseline and fully ends the pointer gesture. Pointer cancellation or loss of window focus cancels the active gizmo drag as well. Selection is cleared if its typed Project object is removed by any document change, including undo/redo. Restoring an object through history does not reselect it. New edits discard redo, and no-op edits add no history. Ctrl/Cmd+Z undoes, Ctrl+Y or Ctrl/Cmd+Shift+Z redoes; focused form fields retain native shortcuts.
