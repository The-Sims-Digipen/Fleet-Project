# Editing and history

`beginEdit`, `commitEdit`, and `cancelEdit` group continuous changes into one undo step. Number fields preview valid values while typing, commit on blur or Enter, and cancel on Escape. Sliders group pointer drags and held arrow keys; pointer cancellation restores the starting value. Color edits group until the picker loses focus. Presets and checkboxes are discrete edits. Blank or invalid numeric drafts stay local to their control.

Selection, catalog creation/deletion, reset actions, panel collapse, history navigation, and transform-tool setting changes finish pending edits. Undo includes object properties, creation/deletion, lighting, and resets; selection, model loading, camera movement, and panel expansion are excluded. Viewport gizmo drags use the same lifecycle: pointer down begins an edit, live transforms update the document, pointer up commits one undo step, and Escape cancels back to the drag baseline and fully ends the pointer gesture. Pointer cancellation or loss of window focus cancels the active gizmo drag as well. Selection is cleared if its object is removed by any document change, including undo/redo. Restoring an object through history does not reselect it. New edits discard redo, and no-op edits add no history. Ctrl/Cmd+Z undoes, Ctrl+Y or Ctrl/Cmd+Shift+Z redoes; focused form fields retain native shortcuts.
